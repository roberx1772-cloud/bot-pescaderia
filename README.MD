# Bot de WhatsApp para Pescadería 🐟

Bot de automatización para WhatsApp desarrollado con Node.js y `whatsapp-web.js` orientado a la gestión de mensajes de bienvenida, consultas y envíos masivos programados.

## 🚀 Características
- **Auto-respuesta inteligente:** Responde automáticamente dentro y fuera del horario comercial.
- **Envíos masivos automatizados:** Envío de promociones en texto o imagen con delays aleatorios para prevenir bloqueos.
- **Panel de comandos por chat:** Control total mediante comandos privados (`#ayuda`, `#mensaje`, `#reparto`, `#parar`, `#status`).
- **Persistencia local:** Manejo de listas de clientes e historial en JSON/Excel.

## 🛠️ Tecnologías utilizadas
- Node.js
- whatsapp-web.js
- qrcode-terminal
- dotenv
